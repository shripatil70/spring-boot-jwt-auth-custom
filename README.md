# Spring Boot JWT Authentication

A secure authentication and authorization system built using **Spring Boot**, **Spring Security**, and **JWT (JSON Web Tokens)**.  
This project demonstrates real-world backend authentication with role-based access control.

---

## 🚀 Features

- User Registration & Login
- JWT-based Authentication
- Refresh Token Support
- Role-Based Authorization (USER / ADMIN)
- Secure Password Hashing (BCrypt)
- RESTful APIs
- Exception Handling
- MySQL / H2 Database Support

---

## 🛠 Tech Stack

- Java 17
- Spring Boot
- Spring Security
- JWT (Access Token & Refresh Token)
- Spring Data JPA
- Hibernate
- Maven
- MySQL / H2
- Postman (API Testing)
